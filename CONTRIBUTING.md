# Contributing to NPATI Agent

Thank you for helping. Bug reports, ideas and pull requests are welcome.

## Before you start

- Search the existing issues first. For a larger change, open an issue and describe the idea before writing code.
- Security problems go through a private report, not a public issue: see [SECURITY.md](SECURITY.md).

## Pull requests

- Keep a pull request to one change, with a short description of what and why.
- Run `npm run typecheck`, `npm run lint` and `npm test` before you open it, and add a test for a fixed bug.
- Do not commit `.env`, keys, tokens or other secrets.
