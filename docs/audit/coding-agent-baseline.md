## Визначення метрик

| Метрика | Як рахується |
|---|---|
| Час до першої дії | від POST до старту першого tool call (`created_at − durationMs` події `tool_call`), з поправкою на різницю годинників host/БД |
| Загальний час | від POST до завершення останнього run компанії (включно з візуальними ремонтами й фоновими run) |
| Виклики моделі | події `model_call` `phase=completed` без `attempt` (по одній на виклик), **включно з self-review** |
| Tool calls | події `tool_call` (включно з системною верифікацією, яку runner записує як tool call) |
| Write | tool calls інструментів запису (`code.fs.write/edit/apply_patch/move/delete`, `code.deps.add`, `code.data.*` writes) |
| Змінені файли | шляхи з аргументів записів у replay (`code.fs.*`) |
| Успіх | S1: run `completed`; S2: у зміненому файлі є `#16a34a`; S3: run `completed` і візуальна приймальна перевірка не `failed`; S4: 0 write і 0 змінених файлів; S5: міграція з `orders` у `data_backend_migrations`; S6: файл сторінки `about` у дереві проєкту |

## Що видно з baseline (факти з даних)

1. **Зайві цикли й ремонти — головний час у S3.** deepseek: 3 run-и (2 візуальні ремонти), 392 с; gemma: 3 run-и, ≥ 949 с і все одно `visual_acceptance_failed`.
2. **Зайвий self-review для правки лише CSS.** deepseek S2: 5 викликів моделі, з них 1 self-review, хоча змінено тільки `app/globals.css`. Причина в коді: для CSS-only правки сайту системна перевірка — Preview після run, тому на момент рішення верифікація `not_run`, а пропуск дозволено лише при `passed` (`code-self-review-risk.ts`).
3. **Помилки без підказки → цикл.** gemma S5: `Invalid field type: STRING` (потім `TEXT`) без переліку допустимих типів → 4 невдалі `schema.apply` і `loop_detected`. gemma S1: 3 × `unchanged` (old_string == new_string) → `loop_detected`.
4. **Довгий старт створення сайту — до агента.** deepseek S1: проєкт створено на +4,5 с, run агента стартував на +62 с; ~57 с займає підготовка шаблону Next.js до циклу (не тема цього етапу, але найбільша частка часу до першої дії в S1).
5. **Аналіз зовнішнього сайту не йде через Coding Agent** — обидві моделі відповіли звичайним чатом без завантаження сторінки (deepseek: «аналіз спирається на загальновідомий вміст»; gemma: «немає доступу до зовнішніх сайтів»). Вимога «0 write» виконана, але сам аналіз не виконано.
6. **Зайвих файлів у правках не виявлено:** S2 — лише `globals.css` в обох моделях; S6 зачіпає сторінку, навігацію (`SiteHeader.tsx` або `page.tsx`) і стилі.
