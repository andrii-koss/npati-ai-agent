# Browser Research: Future Boundary

This milestone intentionally supports public, read-only research through OmniRoute search/fetch and Crawl4AI.

Browser Use is reserved for a later milestone. That future capability may cover interactive JavaScript websites, clicking, navigation, form filling, and authenticated workflows with explicit user permission. It must have its own permission model, session isolation, audit trail, secret boundary, and defenses against prompt injection.

The current milestone does not add a Browser Use package, Docker service, browser session API, login automation, form submission, or autonomous website actions.
