# Media for README and documentation

Put GIFs and screenshots for the main README and the user guide here.

## File names

Short, lowercase, words joined with a hyphen, one feature per file:

- `chat-create-website.gif`
- `game-snake-preview.gif`
- `projects-page.gif`
- `data-studio-rows.gif`
- `telegram-bot.gif`

## Size

- Width about 1280 px, length up to 15 seconds.
- Keep each GIF under 10 MB (GitHub shows larger files slowly or not at all). A longer clip is better as MP4.
- Hide keys, tokens, e-mail addresses and phone numbers before recording.

## Using a file in README.md

```markdown
![Create a website from the chat](docs/media/chat-create-website.gif)
```
